## ✦ Overview

This repository contains the **Premium 3D Web Animations** architecture and skill definitions for the Antigravity Skills Engine (ASE). It is designed to act as the authoritative baseline for AI agents and developers building high-fidelity, 60fps 3D web experiences.

It enforces strict performance rules, memory management protocols, and provides a suite of advanced GLSL, React Three Fiber (R3F), and vanilla Three.js templates.

---

## ⚡ The Seven Laws of WebGL Performance

We treat the browser as a film studio. Every scene generated by this architecture adheres to the following non-negotiable rules:

1. **Zero Render Loop Allocations**: Banning `new THREE.*` inside `requestAnimationFrame`.
2. **Strict Pixel Ratio Caps**: Hard-capped at `Math.min(devicePixelRatio, 2)`.
3. **Strict Draw Call Budgets**: Kept under 100 via InstancedMesh and merged geometries.
4. **Explicit Blending Orders**: Carefully managed `renderOrder` and `depthWrite` flags.
5. **Aggressive Garbage Collection**: Mandated `.dispose()` on unmount for all geometries, materials, and textures.
6. **High-Performance Context**: WebGL Context requested with `powerPreference: 'high-performance'`.
7. **GPU-Tier Adaptive Quality**: Dynamic feature toggling based on the user's detected hardware tier.

## 🎨 Advanced Capabilities

This engine provides ready-to-use boilerplate and shader templates for:

- **GPU-Instanced Particle Systems**: Capable of rendering 100,000+ animated particles in a single draw call.
- **Cinematic Scroll Orchestration**: Seamlessly syncing camera paths and model rotations to the scrollbar using GSAP ScrollTrigger.
- **Advanced Post-Processing Pipelines**: Configured for Bloom, Chromatic Aberration, Depth of Field, and Film Grain.
- **Procedural Background Shaders**: Zero-geometry, fullscreen GLSL environments utilizing Fractal Brownian Motion (fBm) noise.
- **Physically Based Rendering (PBR)**: Configurations for frosted glass, chrome, and glowing plastics with Image-Based Lighting (IBL).

## 🛡️ No-GPU / Software Rendering Fallback

Not every user has a dedicated GPU. Hardware acceleration can be disabled, resulting in unplayable framerates on standard WebGL.

This repository includes a **premium fallback strategy** using **CSS3D and GSAP**. 
Located in `examples/apex-landing/`, this strategy demonstrates how to build an immersive, award-winning parallax experience running entirely on the browser's compositor thread—requiring zero WebGL.
